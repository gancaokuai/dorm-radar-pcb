# 防宿管雷达 PCB 设计基准 v0.1

## 1. 已确定约束
- 发射端和接收端使用 ESP-NOW。
- 无线链路距离约 2m，需要穿过一面墙。
- 雷达探测不需要穿墙。
- 红外对射方案取消。
- 接收端只需要 LED 提示。
- PCB 不设计充电功能。
- 电池允许使用多节 18650。
- 目标最低连续工作时间 24h。

## 2. 推荐系统形态
检测端：
LD2450 雷达 + ESP32-C3-MINI-1 + 1S3P 18650 + 5V 升压 + 3.3V LDO

接收端：
ESP32-C3-MINI-1 + LED + 1S2P 18650 + 5V 升压 + 3.3V LDO

建议做一块通用 PCB，通过元件不安装和固件选择实现两种版本：
- TX 版本：安装 LD2450 接口。
- RX 版本：不安装 LD2450，安装 LED。

## 3. 初步电路模块
1. 1S 锂电池输入
   - XT30 或 JST-VH 接口
   - 2A 保险丝或自恢复保险丝
   - 反接保护 P-MOSFET
   - TVS 和输入滤波电容
   - 不设计充电、均衡和电量计
2. 5V 升压
   - MT3608 作为初版方案
   - 5V 输出给 LD2450 和 3.3V LDO
   - 峰值输出能力按 0.8A 以上设计
3. 3.3V 电源
   - AP2112K-3.3 或同等级 600mA LDO
   - 给 ESP32-C3-MINI-1、LED 和调试接口供电
4. 主控
   - ESP32-C3-MINI-1，独立模块
   - EN 复位 RC、BOOT 上拉、去耦电容
   - 预留 TX/RX/EN/BOOT/GND/3.3V 调试焊盘或排针
5. 雷达接口
   - LD2450 5V、GND、TX、RX
   - 先按 3.3V UART 设计，正式布线前核对雷达数据手册
   - 雷达建议通过短排线外接，避免载体板地平面影响 24GHz 天线
6. LED
   - ESP32 GPIO 串 1k 电阻驱动单颗 LED
   - 低亮度版本不需要 MOSFET

## 4. PCB 初步指标
- 层数：2 层
- 板材：FR-4，1.6mm
- 铜厚：1oz
- 暂定尺寸：55mm x 30mm，不含外接电池组
- 电池组通过连接器外接，PCB 上不焊 18650 电池座
- 四角预留 M2.5 安装孔
- 雷达和 ESP32 天线分别布置在板两端

## 5. 布局要求
- ESP32-C3-MINI-1 天线端放在板边，天线投影区禁止铺铜和放金属件。
- 电池、电感、升压电路和雷达尽量远离 ESP32 天线。
- MT3608 的输入电容、电感、二极管和输出电容形成最小回路。
- 5V 和电池走线按至少 1A 设计，关键电源走线加宽并多打过孔。
- LD2450 若直接上板，其天线前方和下方必须按厂家说明保留净空。
- 雷达模块建议通过 5-pin 1.27mm 排线外接，便于调角度和减少遮挡。
- 接收端天线保持竖直，避免紧贴电池和金属外壳。

## 6. 电源估算
按 3 节 3500mAh 18650 并联：
- 标称能量约 38.9Wh。
- 可用能量按 80% 估算约 31Wh。
- 检测端平均功耗按 0.6-0.8W 估算。
- 预计续航约 39-52h。

按接收端 2 节 3500mAh 18650 并联：
- 标称能量约 25.9Wh。
- ESP32 持续接收场景预计可工作 50h 以上。
- LED 只在触发时点亮，对续航影响很小。

## 7. 后续必须确认
- 是否接受外接 18650 电池组，还是要求电池座集成到 PCB。
- PCB 最大允许尺寸和外壳安装方式。
- LD2450 使用外接排线还是直接贴装在 PCB 上。
- 编程方式使用 6-pin 排针、焊盘，还是增加仅用于数据编程的 USB-C。
- 墙面材质和 ESP-NOW 实测链路余量。
